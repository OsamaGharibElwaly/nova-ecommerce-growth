# E-commerce CRO Audit

## Product detail page checklist
- [ ] Multiple clear product images
- [ ] Accurate title, price, and availability
- [ ] Useful description and material details
- [ ] Size / fit guide where relevant
- [ ] Delivery fees and estimated delivery timing visible
- [ ] Return and exchange policy easy to find
- [ ] Reviews shown only when genuine and permissioned
- [ ] Clear add-to-cart action
- [ ] Mobile layout tested
- [ ] Checkout has no unnecessary steps

## Funnel diagnosis
Review sessions, product views, add-to-carts, checkout starts, and purchases by device, source, landing page, and product category.

## Prioritization
Score each issue by expected impact, confidence, and implementation effort. Treat recommendations as hypotheses until validated with experiments or observed data.
